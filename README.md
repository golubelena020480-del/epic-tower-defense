# Epic Tower Defense Game 🎮

Крутая браузерная Tower Defense игра с **3D графикой**, **30+ типами башен и врагов**, красивым **UI** и полной игровой механикой!

## 🎯 Возможности

✅ **30+ юнитов** - 10 типов башен + 12+ типов врагов  
✅ **3D мир** - На Three.js с красивой графикой и освещением  
✅ **Красивый UI** - Киберпанк дизайн с неоновыми эффектами  
✅ **Волновая система** - Прогрессивная сложность  
✅ **Система ресурсов** - Золото, жизни, очки  
✅ **2400+ строк качественного кода**  
✅ **Динамическая сложность** - Враги становятся сильнее с волнами

## 🎮 Как Играть

1. **Выберите башню** - Нажмите на башню слева
2. **Разместите башню** - Кликните на поле
3. **Запустите волну** - Нажмите кнопку "Start Wave"
4. **Уничтожайте врагов** - Башни автоматически стреляют
5. **Получайте золото** - За каждого убитого врага
6. **Усиливайте базу** - Покупайте новые башни
